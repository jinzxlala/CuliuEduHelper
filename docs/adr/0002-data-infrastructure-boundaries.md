# ADR-0002：正式数据、任务与文件存储边界

- 状态：Accepted
- 日期：2026-08-01

## 背景

MVP需要同时处理匿名讲座知识、机构真实学生资料、长任务和不可变证据文件。Meilisearch不能承担正式事实来源，队列也不能成为授权来源；本地开发文件必须能够无缝替换为云端对象存储。

## 决策

1. PostgreSQL 16是正式业务数据、证据关系、冻结授权上下文、任务状态和审计事件的事实来源；Meilisearch仅保存可重建的匿名检索索引。
2. `knowledge`与`student`是显式数据域。知识域记录不得带`student_id`，学生域记录必须带`student_id`；数据库检查约束和触发器共同阻断跨域、跨学生证据引用。
3. `source_document`、`evidence_object`、`evidence_locator`、`authorization_context_snapshot`和`audit_event`采用追加/版本化语义，禁止原地更新或删除。
4. 本地文件适配器按SHA-256寻址，只提供写入一次与校验读取能力，不提供覆盖或删除接口。学生对象路径包含学生UUID；知识对象进入独立前缀。
5. BullMQ任务只携带任务输入和冻结授权上下文的ID/哈希。Worker必须重新校验Schema，不能接受任务或模型返回的新学生ID来扩大范围。
6. PostgreSQL、Redis和Meilisearch仅绑定`127.0.0.1`；真实密码只存在被Git忽略的`infra/.env`。Compose使用固定镜像版本和命名卷。
7. 脱敏fixtures只使用固定UUID、`.invalid`邮箱和明确的`synthetic`值，不包含真实学生资料。

## 后果

- 后续知识导入、学生画像和课程规划必须复用这些数据域及不可变证据约束，不能另建绕过路径。
- 正式删除、授权撤销和数据保留策略需要新增受审计的领域操作，不通过直接删除证据行实现。
- 云端COS适配器必须保持与本地适配器相同的内容哈希、数据域和学生路径语义。
- 新任务类型必须新增Zod联合分支、处理器、幂等测试、重试/失败测试和授权负例。
